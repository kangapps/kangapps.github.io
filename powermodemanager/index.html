PowerModeManager

Manage your Mac’s power settings with Server and Normal profiles. Preview changes, then back up or restore your current settings.

macOS 13 or later Apple Silicon and Intel English and Korean

The public download will be added after installation and device compatibility checks are complete.

What it does

01

Preview before applying

Review the power settings a profile will change before you apply it.

02

Switch between profiles

Choose Server Mode for continuous operation or Normal Mode for everyday sleep and power saving.

03

Back up and restore

Save your current power settings locally and restore them when you want to return to a previous setup.

04

Check and diagnose

Review power settings and active sleep assertions, then save a local diagnostic report.

For macOS

macOS 13 or later

Apple Silicon and Intel

A Universal build is prepared. Installation and device compatibility checks are still in progress.

Before applying a profile

Keep MacBooks connected in Server Mode

Server Mode disables automatic sleep on battery too, which can drain a MacBook’s battery. Power setting changes require administrator approval.
